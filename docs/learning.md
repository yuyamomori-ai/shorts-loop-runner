# 継続制作と学習

## 有効化

`SHORTSLOOP_GROWTH_REQUEST` に一意な運用リクエストIDを設定すると、起動時に一度だけ制作費に応じた本数調整と自作動画の品質改善を有効にする。既存の公開設定、手動一時停止、権利・事実・安全性による停止、Googleの追加承認フラグは変更しない。

日次の開始操作は不要。常駐schedulerが残額・キュー・再試行時刻を確認し、企画、根拠照合、制作、品質検査、自動承認、予約送信、公開確認を進める。公開確認では保存したYouTube IDを問い合わせ、同じ動画を再送信しない。

## 費用

- 月の総予算目標10,000円のうちAI制作枠6,000円、サーバー・税・為替の予備4,000円を維持する。
- 制作完了が5本未満の間は1本100円の保守的見込み。以降は完了動画の80パーセンタイルに30%の余裕を加えた額と、失敗分込みの平均費用の大きい方を使う。
- 月の残額を残日数に配分し、当日の支出、AI呼出し回数、投稿間隔、成熟した実績からの減速判断も尊重する。当日の再企画は最大でも目安本数の3倍。制作中の動画があれば先に処理する。
- 5分の再企画間隔と試行回数をDBに保存する。再起動で費用予約や試行回数を消さない。
- 金額は請求書ではなく保守的な管理額。各AIリクエスト前の永続化された月額予約が最終防御となる。ホスティング費や他アプリのAPI使用はこの台帳の対象外。
- 総額を管理するには請求サービス側の上限も必要。Railwayの [Workspace Usage](https://railway.com/workspace/usage) にComputeのHard limitがある。[公式説明](https://docs.railway.com/pricing/cost-control)。サブスクリプション、税、カードの換算額も別途含めて確認する。

## 今すぐ使う制作改善

[YouTube公式のCreator Insider対談紹介](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/)（2025-01-28）の文章を確認した要約を利用する。動画全編を視聴した記録ではない。

冒頭の視覚的な問い、小さな物語、約束した疑問への答え、最初のフレームの重要性を企画と映像設計に含める。自作の直近3本の安全なVisual QA指摘も入力し、一つの具体的改善を `editorialTrial` に記録する。これは制作品質の改善であり、再生実績から学んだ証拠として扱わない。

## 視聴実績からの学習と人気動画の参考

`YOUTUBE_DERIVED_METRICS_APPROVED=true` は、対象用途についてGoogleの追加条件・手続きを満たしたことが確認された場合のみ設定する。ユーザーが学習を希望したという理由だけでは設定しない。

- [Derived Metrics Policy](https://developers.google.com/youtube/terms/derived-metrics-policy)
- [YouTube API Services申請フォーム](https://support.google.com/youtube/contact/yt_api_form) の Analytics & Reporting

有効になった後も、公開確認済み・実際のYouTube Analytics・完全な7集計日・100エンゲージビュー以上の観察だけを使う。一度の同期で最大2本（高再生と低再生）を比較し、未取得項目をゼロで捏造しない。同じ観察は再分析せず、指標が更新された時だけ再検討する。成功理由は仮説であり因果の証明ではない。

編集特徴の配分変更は20本以上、比較グループそれぞれ8本以上など既存の標本条件を維持。探索30%を残す。投稿ペースの実績調整には成熟した14日・各期間10本以上を要求し、費用による本数上限を超えない。

人気動画の候補は日本向けの科学・雑学の英語/日本語メタデータ検索から、APIで確認した50万再生以上の短尺を選ぶ。短尺であることだけでShorts分類を断定しない。実際に取得できたタイトルとサムネイルを参考にする。全文の台本、映像、音楽は取得・転用せず、見ていない編集や音声の特徴を推測で記録しない。検索キャッシュ・鮮度確認・データ削除処理を維持する。

追加条件の確認前はこのAPIデータを使う学習・人気動画分析を保留し、公式講座と自作QAによる制作改善を続ける。UIでも両者を区別する。

## 申請用途の説明案

ShortLOOPは所有者本人の日本語知識系チャンネルに、出典を確認した独自台本、AI日本語ナレーション、自作図解を含む短尺動画を制作・投稿する。所有者の許可を得たYouTube Analyticsの観察値を同じ7日間で比較し、次の編集で試す一要因の仮説を作る。公開動画のAPIメタデータについては50万再生以上の短尺を探し、タイトルとサムネイルから観察可能な構成の参考を記録する。動画や音楽の無断取得、架空の視聴者属性や未取得指標の生成、成長の保証は行わない。

これは用途説明の下書きで、Googleへの申請・承認の記録ではない。申請者情報、Cloudプロジェクト番号、公開プライバシーポリシー、画面記録、各遵守項目の確認は実際の情報を用意してから提出する。
